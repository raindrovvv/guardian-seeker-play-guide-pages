01 / 플레이 전 준비 사항

빌드 파일 다운로드 & 실행

아래 순서에 따라 게임 빌드를 다운로드하고 실행해주세요. 두 플레이어 모두 각자 실행해야 합니다.

1
구글 드라이브에서 빌드 파일 다운로드

아래 링크에 접속하여 Client.zip 파일을 다운로드합니다.

📂  빌드 파일 다운로드 (Google Drive)
Google Drive — Client.zip 선택
2
Client.zip 압축 해제 후 GASClient.exe 실행

다운로드한 Client.zip을 압축 해제하면 아래와 같은 파일 구조가 나타납니다. GASClient.exe를 더블클릭하여 실행합니다.

압축 해제 후 파일 구조 — GASClient.exe 실행
💡
두 플레이어 각자 실행
심사 시 두 분이 각각 빌드를 실행하여 멀티플레이로 진행합니다.
02 / 로비 진입

게임 로비 진입 방법

메인 화면에서 두 단계를 거쳐 커스텀 게임 로비로 입장합니다.

1
메인 화면 → [Play] 클릭

게임 실행 후 메인 화면이 나타나면 Play 버튼을 클릭합니다.

메인 메뉴 — Play 클릭
2
서브 메뉴 → [Custom Game] 클릭

Play 클릭 시 서브 메뉴가 펼쳐집니다. Custom Game을 선택하면 커스텀 로비로 입장합니다.

Play 서브 메뉴 — Custom Game 클릭
3
커스텀 로비 화면 확인 & 버튼 안내

캠프파이어가 있는 야외 대기 화면이 나타나면 정상 입장입니다. 좌측 세 버튼으로 캐릭터 선택, 던전 에디터 진입, 역할 변경이 가능합니다.

커스텀 로비 — 입장 화면
커스텀 로비 — 좌측 버튼 안내
⚠️
양측 모두 Ready 필수
시커와 가디언 플레이어 모두 Ready 버튼을 눌러야 게임이 시작됩니다.

04 / 던전 에디터

가디언의 던전 설계 가이드

로비에서 '던전 에디터' 버튼을 눌러 진입합니다. 한정된 넥타르(Nectar) 예산 안에서 방, 함정, 몬스터를 배치해 던전을 설계합니다.

💎  넥타르 초기 예산: 6,000  (오브젝트 배치 시 소모)
던전 에디터 — Room 탭 전체 화면 (우측 상단 조작키 안내 포함)
⚠ 반드시 배치해야 할 요소 2가지
① 보스룸 (BossRoom)
Room 탭 하단 BossRoom 섹션 → 시커의 최종 목적지
② 시커 스타트 포인트
Trap 탭 Floor 섹션 → 시커가 던전에 진입하는 출발 지점
🔗
경로와 보스룸 입구 연결에 주의
모든 방과 통로는 반드시 연결되어야 합니다. 특히 보스룸은 입구가 트여 있는 방향과 통로가 정확히 이어지도록 배치해주세요. 입구가 잘 보이지 않아 막힌 벽 쪽으로 연결하면 게임 진행이 불가능할 수 있습니다. 추후에는 보스룸 입구 방향 표시와 함정 데미지 방향 표시를 추가해 배치 실수를 줄일 예정입니다.

05 / 게임 시작

Ready & 게임 진행 흐름

던전 설계를 마친 후 양측이 Ready를 누르면 매치가 시작됩니다.

1
양측 플레이어 모두 [Ready] 클릭

로비 우측 하단 Ready 버튼을 클릭합니다. 시커와 가디언 모두 Ready 상태여야 게임이 시작됩니다.

커스텀 로비 — Ready 버튼 위치
⚠️
한 명만 Ready이면 시작 불가
두 플레이어 모두 Ready를 눌러야 매치가 시작됩니다.
2
탐험 페이즈 → 보스전 페이즈 순서로 진행

시커는 던전을 탐험하며 보스룸으로 전진합니다. 가디언은 RTS 시점으로 몬스터를 지휘해 시커를 저지하다가, 보스룸 도달 시 드라카로 변신해 직접 대결합니다.
